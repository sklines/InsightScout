PACKAGE v1
숨은공학 소재발굴/심층분석 GPTs 사용방법
  1. GPT 심층분석용 복사를 눌러 현재 소재의 SCOUT 데이터 패키지를 복사합니다.
  2. 별도로 만든 숨은공학 소재발굴/심층분석 GPTs에 붙여넣습니다.
  3. GPTs가 웹 검색·공식자료·논문·해외 사례 등을 추가 조사해 독립적으로 판단하도록 합니다.
  4. GPTs가 출력한 프로그램 등록용 분석 결과를 복사합니다.
  5. 아래에 붙여넣고 GPT 결과 적용을 누르면 SCOUT 판단과 나란히 비교합니다.
독립 판단 원칙 · SCOUT 점수와 추천이 높더라도 GPT는 동의할 의무가 없습니다. 판단 불일치는 그대로 보존합니다.

YouTube Data API 키

브라우저 localStorage 저장
한 줄에 API 키 하나씩 붙여넣으세요. 등록 순서대로 별칭이 000, 001, 002... 자동 부여됩니다. 빈 줄과 중복 키는 자동 제외합니다.
이 화면의 사용량은 Google의 실제 quota 조회값이 아니라 INSIGHT SCOUT가 계산한 로컬 예상치입니다. 다음 요청까지 실행하면 로컬 예상 사용량이 95%를 넘는 키는 그 요청부터 자동으로 건너뜁니다. 여러 API 키가 같은 Google Cloud 프로젝트에 속하면 프로젝트 quota를 공유할 수 있으므로, 키가 여러 개라고 해서 quota가 키 수만큼 늘어난다고 단정할 수 없습니다. 공개 배포 파일에는 개인 API 키를 하드코딩하지 마세요.
