처음 설치할 때와 다음 사용 시 안내

처음 사용하는 경우 INSIGHT_SCOUT_HELPER_WINDOWS_v4_0.exe를 다운로드해 더블클릭하세요. Python 설치·압축 해제·BAT 실행이 필요하지 않습니다.

검은 Helper 창이 열리고 Listening on http://127.0.0.1:포트가 나오면 이 웹사이트 화면은 그대로 둔 채 ‘다시 연결 · 스크립트 가져오기’를 누르세요. 사용을 마치면 Helper 창을 닫아도 됩니다.

다음부터는 스크립트 또는 첫 화면 복사가 필요할 때 EXE 하나만 실행하면 됩니다. 첫 사용 시 yt-dlp·FFmpeg·Deno를 사용자 캐시 폴더에 자동으로 내려받아 사용하므로 인터넷 연결이 필요할 수 있지만 별도 설치는 하지 않습니다. Helper 본체는 C#/.NET Framework 기반이며 Python·Go 설치가 필요 없습니다. 공개 웹사이트와 로컬 file:// 테스트를 지원합니다. 자막이 없는 영상은 whisper.cpp가 자동 fallback으로 동작합니다.

Helper는 8766을 먼저 사용하고 막혀 있으면 8767~8770 또는 18766~18770으로 자동 전환합니다. 연결이 계속 실패하면 Helper 창에 표시된 실제 포트 뒤에 /health를 붙여 새 탭에서 열어 보세요. 상태 페이지는 열리는데 SCOUT 연결만 실패하면 브라우저의 로컬 네트워크 접근 허용 여부를 확인하세요.

웹사이트 관리자는 HTML과 같은 폴더에 INSIGHT_SCOUT_HELPER_WINDOWS_v4_0.exe도 함께 게시해야 ‘Helper 다운로드’ 링크가 작동합니다. 이 개인 빌드는 코드 서명이 없으므로 Windows가 게시자 확인 경고를 표시할 수 있습니다.

원문

스크립트는 요청 시에만 가져와 브라우저에 저장합니다. 원문을 가져오면 브라우저에서 MyMemory 무료 웹 번역을 자동으로 시도하며 원문 텍스트가 외부 서비스로 전송됩니다. 익명 한도는 하루 5,000자이고 번역 품질·언어 지원·연결 가능 여부는 서비스 측 조건에 따릅니다. 실패하면 무료 웹 번역 열기(수동)를 사용할 수 있습니다. 번역에 실패해도 원문은 유지됩니다. 현재 웹사이트를 그대로 열어 둔 상태에서 Helper를 수동 실행할 수 있습니다. 단일 EXE v4.0.1은 공개 자막/자동자막을 우선 가져오고, 자막이 없는 영상은 Python 없이 whisper.cpp + 다국어 base 모델로 음성→텍스트를 자동 시도합니다. 최초 음성인식 때만 약 142MiB 모델과 소형 Windows 런타임을 사용자 캐시에 내려받을 수 있습니다. 영상·네트워크에 따라 스크립트 취득이 실패할 수 있습니다.
